## Goal


Create a universal, configurable code-review and audit layer that can route code changes to one or more independent AI review engines and deterministic validators.


The system must not depend on Codex, Claude, Gemini, Antigravity, or any single vendor.


Each reviewer is an adapter behind one CISEM review contract.


## Active Finish Line


This CoreCycle is complete when:


1. A governed Review Engine Registry exists.
2. At least two independent AI reviewer adapters can be configured.
3. Mechanical validators run independently of AI reviewers.
4. All findings are normalized into one canonical schema.
5. Conflicting reviewer findings are reconciled by evidence.
6. The builder cannot act as the sole approver of its own work.
7. Every review produces evidence, disposition, and a final verdict.
8. The process runs without Yariv unless a Governor Gate is triggered.

## Builder–Reviewer Separation


Mandatory rule:


> The builder may contribute self-review, but may never be the sole approval source for its own work.


For Antigravity-built code:


- Antigravity self-review is supplementary.
- At least one independent reviewer is required.
- High-risk Core changes require the active review profile’s minimum independent review coverage.


## Workflow


```text
Builder completes bounded change
→ immutable diff or review package created
→ mechanical validators run
→ review profile resolves required reviewers
→ review requests dispatched
→ findings normalized
→ duplicates consolidated
→ conflicts identified
→ CISEM auditor evaluates evidence
→ builder receives integrated correction package
→ approved fixes applied
→ mechanical checks rerun
→ blocking findings independently rechecked
→ final verdict recorded
```


## Conflict Resolution


When reviewers disagree:


1. Compare evidence, not model prestige.
2. Reproduce claims mechanically where possible.
3. Separate factual defects from architectural preferences.
4. Apply governing artifacts and acceptance criteria.
5. Add another reviewer only when it provides distinct evidence.
6. Escalate to Yariv only through a genuine Governor Gate.


Do not resolve by majority vote alone.
