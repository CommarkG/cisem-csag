## 3. Archival Protocol for Superseded Draft Files

Once the 5 Consolidated Master Architecture Artifacts are authored and signed off:
1. All 92 historical source draft plan files will be moved into `cisem_core/planning/_draft_archive/`.
2. Each archived file will carry an explicit header: `# STATUS: CONSOLIDATED_INTO_MASTER_ARTIFACT — ARCHIVED`.
3. The root `cisem_core/planning/` directory will contain ONLY the 5 Consolidated Master Architecture Artifacts plus `ratified_plans_manifest.json`.
