CXP Packet Schema V1.2

Detailed mapping of the structured communication interface. Every transaction, plan validation, or execution handshake is packed, signed, and validated against these constraints.

protocol object

Defines protocol type and core configuration contracts.

Required: protocol_name protocol_version schema_version adapter_contract_version
Property Type Description
protocol_name string Must be exactly "CXP"
protocol_version string Current protocol version (e.g. "1.2")
schema_version string Current schema version constraints (e.g. "1.2")
adapter_contract_version string Version identifier of the running adapter contract
repository_snapshot string Optional git reference hash matching the current checkpoint

identity object

Identifies ownership layers and structural boundaries of the package.

Required: project core_cycle purpose
Property Type Description
project string Name of the target project or application endpoint
core_cycle string Cycle token representing current sprint (e.g., "01")
purpose string Short description of why this specific packet exists

immutable_request object

The request parameter block written by the sender. Never modified after creation.

Required: header repository_target authority governance execution
Property Type Description
header object Contains packet_id matching regex pattern and sender/recipient descriptors
repository_target object Defines absolute execution path, target branch, and dirty state checks
authority object Credential profiles for ratifying governor, adapters, and human-bridge keys
governance object Dependencies list, blocking gates, and targeted acceptance criteria
execution object Requested intent (e.g. TEST_HANDSHAKE), input parameters, and required output items

event_stream array [object]

An append-only chronological list of state events. Once logged, events cannot be modified.

Required: event_id event_type sequence_number transition payload
Property Type Description
event_id string Unique ID matching regex pattern CXP-EVT-YYYYMMDD-XXXXXX-XXXXXX
event_type string (enum) CREATED, CLAIMED, EXECUTING, EVIDENCE_RECORDED, COMPLETED, AUDITED, etc.
sequence_number integer Chronological index of event. Starts at 1. Must be contiguous.
transition object Defines from_state -> to_state mappings and the transition identifier
payload object Dynamic argument context and validation output references

derived_view object

Projection constructed by playing the event stream sequentially. Regenerated dynamically.

Required: current_state execution_control response audit lessons_learned
Property Type Description
current_state string (enum) READY, CLAIMED, EXECUTING, VALIDATING, COMPLETED, FAILED_VALIDATION, etc.
execution_control object Logs lease parameters, actor name, attempt counts, and expiration limits
response object Aggregated execution stdout/stderr streams and captured evidence
audit object State of the audit check (VERIFIED/REJECTED), auditor ID, and timestamp
lessons_learned array [object] Structured learning logs generated during execution to prevent recurring bugs

integrity object

Cryptographic validation blocks to prevent packet alterations or event sequence modifications.

Required: packet_hash latest_event_hash
Property Type Description
packet_hash string SHA-256 hash computed across the entire immutable request block
latest_event_hash string The content hash of the latest event in the sequence, verifying stream continuity
