# Dependency Graph Visualizer Skill

This skill parses python import statements within the workspace and generates a mermaid or D3 graph visualizer to map core dependencies.

## Invocation

Run the graph visualizer via:
```bash
python cisem_core/platform_core/2026-08-10__CISEM__AntigravityLocal__GraphifyDependencyMapper__V1.0.py
```
